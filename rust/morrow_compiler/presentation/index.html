morrow_compiler

Module presentation 

Source
Expand description

Bounded plain-text source types and function signatures for documentation and editors. Consumers own markup escaping. No compiler-generated identity is displayed implicitly.

Structs§

Limits
Per-render structured depth, aggregate node and UTF-8 output byte limits. Limits may be lowered, never raised above the defaults. Source parsing separately retains the parser’s source/token/depth limits; source bodies are not rendered.

Functions§

render_type
Render a validated semantic source type; internal variables and Never are errors. Caller-created trees need no prior validation. Output is plain text, not markup.
render_type_in_context
Render a selected type using its enclosing scheme’s inferred display-name assignment. Explicit variables in both types are reserved first. All work shares one render budget. The enclosing text is discarded; only the selected type is returned as plain text.
render_type_with_names
Render ty, renaming explicitly registered $-prefixed inferred quantifiers. Names are assigned by first occurrence, avoiding every explicit source generic. Duplicate or source-spelled registrations are errors; unknown internal names fail.
resolved_signature
Render finalized parameter/result types with the original source parameter patterns. Guards/body are intentionally excluded: this presents a reusable group signature. The caller supplies source AST, not normalized dispatch AST. Types/patterns/names are bounded and validated; unused body/guard AST is never traversed or cloned.
source_signature
Extract a current source header at its exact fn byte anchor after parsing. Includes pub and the body separator, preserving omissions, patterns and guards. Trailing comments/layout before the body are preserved; no body is included. Invalid source/anchors or excessive output return a diagnostic, never stale text.
