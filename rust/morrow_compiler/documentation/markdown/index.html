morrow_compiler::documentation

Module markdown 

Source
Expand description

Bounded Markdown rendering for documentation pages: escaped HTML, safe links, Morrow highlighting.

The supported dialect is the CommonMark/GFM subset used by Morrow documentation: ATX and setext headings, paragraphs, fenced code, nested lists and task lists, block quotes and GitHub-style alerts, thematic breaks, pipe tables, footnotes, emphasis, strikethrough, code spans, inline and reference links, images and autolinks. Raw HTML passes through an allowlist of structural tags and attributes and is re-balanced; only http, https, mailto, fragment and relative destinations become links or image sources.
