Struct Hub

pub struct Hub { /* private fields */ }
Expand description

Ephemeral authoritative state. Caller supplies a unique boot incarnation and monotonically increasing time. IDs are routing identities, never credentials. The transport must authorize the selected room before every call, not just login.
